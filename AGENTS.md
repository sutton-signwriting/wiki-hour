# Wiki Hour project guidance

This project owns the Wiki Hour workshop paper, slides, session outline, and sources.
Keep published reference works as links; do not duplicate the publication corpus from
`steveslevinski-me`.

- Drafting and local verification are in scope. Sending mail, scheduling, publishing,
  promising participation, and public runtime changes need Steve's explicit instruction.
- Preserve the distinction between a sign language, International Sign, and SignWriting.
- Use FSW/SWU and compatible web components as the production path. Do not recommend
  official Unicode SignWriting as a production basis or an incomplete foundation to repair.
  Explain the authored facial-data loss using the public Facial Orthography Boundary note.
  Attribute that technical assessment accurately; do not imply institutional endorsement.
- Distinguish SWU from official Unicode SignWriting.
- Identify historical Wikimedia evidence, currently checked behavior, and proposed
  capabilities separately. Do not rebuild retired Wikimedia tooling.
- Use public or deliberately supplied sources. Keep mail provenance and private planning
  out of audience-facing exports.
- Publish only audience-facing source and the generated static site. Keep local
  presenter notes, correspondence, and operating records under ignored `private/`.
- Deploy the project site at `/wiki-hour/` using GitHub Pages. Leave the repository's
  custom domain unset so it inherits the organization's existing domain.
- Have a fluent reader approve sign-language examples and translations before presenting
  them as teaching material. Do not draw invented symbols and label them SignWriting.
- Verify links, timing, slide navigation, and print behavior in proportion to the change.
  Keep generated exports separate from authored source and preserve unrelated work.
